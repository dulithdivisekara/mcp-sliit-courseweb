              SUPERPOWER 01
              103-page PDF parsed in 2s
            

            

              Instant Mid-Term Mark Extraction
              පිටු 100ක Exam Mark Sheet එකෙන් Marks හොයමු
              பரீட்சை பெறுபேறுகளை நொடியில் தேடுங்கள்
            

            

              Lecturers publish PDF result sheets containing thousands of student rows. Prompt: "What are the PS mid exam marks for IT25103992?". It searches row #2,543 on Page 98 and reports 15.00/20 (75%) instantly.
              Lecturers ලා දාන පිටු 100ක PDF mark sheet එකේ තමන්ගේ IT number එක හොයන්න scroll කරලා එපා වෙලාද? Agent ගෙන් අහන්න විතරයි තියෙන්නේ — Row 2,543 (Page 98) හොයලා 15.00/20 (75%) කියලා තප්පරෙන් කියනවා!
              விரிவுரையாளர்கள் இடும் 100 பக்க PDF-ல் உங்கள் IT எண்ணை தேடி அலுக்க வேண்டாம். Agent நொடிகளில் Row 2,543 (Page 98)-ஐ கண்டுபிடித்து முடிவை வழங்கும்!
            

          

          

            
          

        


        
        

          

            

              SUPERPOWER 02
              Multi-course deep scan
            

            

              Automated Course Notice Radar
              අලුත් Notices සහ Marks ආපු ගමන් දැනගන්න
              புதிய அறிவிப்புகள் மற்றும் முடிவுகளை அறிய
            

            

              Prompt: "Check what are new updates in SLIIT courseweb". The agent scans your enrolled courses, alerting you that mid-term marks were uploaded and recording links refreshed.
              "Courseweb එකේ අලුත් updates මොනවද?" කියලා ඇහුවම IT2011 (AI/ML) සහ IT2120 (Probability & Statistics) වල Mid-Term marks release වෙලා තියෙන බවත්, lecture recordings update වෙලා තියෙන බවත් agent ක්ෂණිකව කියනවා.
              ஒரே கேள்வியில் உங்கள் அனைத்து பாடங்களின் புதிய அறிவிப்புகள், lecture recordings மற்றும் பரீட்சை முடிவுகளை agent பட்டியலிடும்.

SECURITY & ACCESS

      

        Two authentication methods. 
Zero credential leaks.
        ලොග් වෙන ක්‍රම 2ක්. 
Password කාටවත් පේන්නේ නෑ, ඔක්කොම Local.
        இரண்டு உள்நுழைவு முறைகள். 
பாதுகாப்பானது, முற்றிலும் Local.
      

      

        Your IT number and password stay strictly on your local computer. We never transmit credentials to external servers.
      

    


    

      
      

        

          

            METHOD 01
            For Personal Laptops
          

          

            Interactive SSO with Microsoft MFA
            Interactive SSO (Phone එකෙන් MFA Approve කරන ක්‍රමය)
            Interactive SSO (MFA உடன்)
          

          

            Best for Mac, Windows, and Linux desktops. Playwright launches a browser window, auto-types your credentials, and pauses for Microsoft Authenticator approval. Saved to storage_state.json.
          


          

            

              01
              Set SLIIT_USERNAME & SLIIT_PASSWORD in .env
            

            

              02
              Ask Agent: "Please run interactive_login"
            

            

              03
              Approve prompt on Microsoft Authenticator
            

            

              04
              ✓ Saved locally (Headless ready)
            

          

        

      


      
      

        

          

            METHOD 02
            For Cloud VMs & Docker
          

          

            Headless MoodleSession Cookie
            Session Cookie එක (Cloud VMs & Headless ක්‍රමය)
            Headless Session Cookie முறை
          

          

            Best for headless Linux servers, GitHub Codespaces, or VPS instances where no browser UI exists. Extract your session cookie in 1 click from Chrome DevTools.
          


          

            
          


          

            copy(document.cookie.split('; ').find(r => r.startsWith('MoodleSession=')).split('=')[1])

Frequently Asked Questions

      


      

        

          
            Is my SLIIT password or IT number sent anywhere?
            +
          
          

            No. The MCP server runs 100% locally on your computer over standard I/O (stdio). Your credentials and cookies are stored only in your local .env and storage_state.json.
          

        


        

          
            What if I have Microsoft Multi-Factor Authentication (MFA) enabled?
            +
          
          

            Run the interactive_login tool. It launches a visible browser window, pre-fills your email, and pauses so you can approve the prompt on your Microsoft Authenticator app.
          

        


        

          
            Does this violate SLIIT IT policies?
            +
          
          

            This tool is built strictly for personal educational convenience and respects campus servers with reasonable request intervals. Personal educational use only.
